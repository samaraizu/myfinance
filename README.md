# myfinance — レシート自動記録システム

レシートをスマホで撮る → Googleドライブに保存 → GAS＋Gemini API（無料枠）で読み取り → スプレッドシートに記録・ダッシュボードで可視化。運用コストゼロ。

```
スマホ（ウェブアプリ） ──撮影・送信──▶ receipts_inbox ──▶ Gemini（構造化JSON）
ドライブアプリで直接保存 ─────────────▶      │                     │
                                   10分おきトリガー            明細／レシート シート
                                              │                     │
                              receipts_done / receipts_error     ダッシュボード
```

## 構成

| パス | 役割 |
| --- | --- |
| `src/appsscript.json` | マニフェスト（タイムゾーン、OAuthスコープ、ウェブアプリは本人のみアクセス） |
| `src/Config.js` | 定数・カテゴリ初期値・スクリプトプロパティ読み出し |
| `src/Receipt.js` | Geminiのプロンプト／JSONスキーマ、レスポンス検証、値引き計算、合計チェック（純粋ロジック） |
| `src/Gemini.js` | Gemini API 呼び出し（リトライ1回） |
| `src/Store.js` | スプレッドシート読み書き、二重登録チェック、ログ |
| `src/Processor.js` | `processInbox`（トリガー本体）と1ファイル処理 |
| `src/WebApp.js` / `src/Index.html` | スマホ入力用ウェブアプリ |
| `src/Dashboard.js` | ダッシュボード（数式＋グラフ）構築 |
| `src/Setup.js` | `setup()`：フォルダ・シート・ダッシュボード・トリガーを一括作成 |
| `test/` | 純粋ロジックのユニットテスト（`npm test`） |

## セットアップ

### 1. Gemini APIキーを取得

[Google AI Studio](https://aistudio.google.com/apikey) で「Create API key」。無料枠のままでOK（課金設定はしない）。

### 2. clasp でGASプロジェクトに反映

```bash
npm install
npx clasp login                     # samaraizu の Googleアカウントで認証
```

[Apps Script の設定](https://script.google.com/home/usersettings) で「Google Apps Script API」をオンにしておく。

[script.google.com](https://script.google.com) で新規プロジェクト（スタンドアロン）を作成し、「プロジェクトの設定」からスクリプトIDをコピー。

```bash
cp .clasp.json.example .clasp.json  # scriptId を書き換える（.gitignore 済み）
npm run push
```

### 3. APIキーをスクリプトプロパティに登録

GASエディタ →「プロジェクトの設定」→「スクリプト プロパティ」に追加。

| プロパティ | 値 |
| --- | --- |
| `GEMINI_API_KEY` | 手順1のキー（必須） |
| `GEMINI_MODEL` | 使うモデル名（任意。未設定なら `gemini-2.5-flash`。無料枠対象モデルが変わったらここだけ差し替える） |

### 4. setup() を実行

エディタで `Setup.gs` を開き、関数 `setup` を実行 → 権限を承認。以下が自動で作られる。

- ドライブ直下に `receipts_inbox` / `receipts_done` / `receipts_error`
- スプレッドシート「レシート記録」（ダッシュボード／明細／レシート／カテゴリマスタ／ログ）
- 10分おきの時間主導型トリガー `processInbox`

作成先のURLは実行ログに出る。IDはスクリプトプロパティに保存されるので、再実行しても既存データは消えない。

### 5. ウェブアプリをデプロイ

```bash
npm run deploy
```

またはエディタ右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」（実行ユーザー：自分、アクセス：自分のみ）。発行された `/exec` のURLをスマホで開く。

- iPhone：Safariで開いて 共有 →「ホーム画面に追加」
- Android：Chromeで開いて メニュー →「ホーム画面に追加」

コードを更新したら `npm run push` のあと、エディタの「デプロイを管理」で既存デプロイを新バージョンに更新するとURLが変わらない。

## 使い方

**ウェブアプリ（メイン）**：開く → 撮影 →「送信して読み取る」。10〜30秒で店舗名・日付・品目・合計が表示され、当月合計も更新される。明細合計とレシート合計が合わなければ注意が出る。

**ドライブに直接保存（予備）**：Googleドライブアプリで `receipts_inbox` に写真をアップロードすれば、10分以内にトリガーが拾う。

**カテゴリ・予算**：`カテゴリマスタ` シートでカテゴリ名を追加・変更、B列に月予算を入れるとダッシュボードで80%超は黄色、超過は赤。カテゴリを31個以上に増やしたら `rebuildDashboard` を実行。

**エラー時**：失敗した画像は `receipts_error` に移り、`ログ` シートに理由が残る。`retryErrors` を実行すると受信フォルダに戻って再処理される。

## 仕様メモ

- **金額の扱い**：明細シートの「金額」は値引き後、「値引き」は値引き額。当月合計・月別推移はレシート合計（実際の支払額）、カテゴリ別・ランキングは明細ベース。外税レシートだとカテゴリ合計は税抜になる。
- **合計チェック**：明細合計＝合計（内税）または 明細合計＋税＝合計（外税）のどちらかが ±1円以内なら OK、それ以外は `レシート` シートで「要確認」が赤表示。
- **二重登録防止**：ドライブのファイルIDをレシートIDとして記録し、登録済みIDはスキップ。
- **レート制限対策**：トリガー1回あたり最大5枚、呼び出し間隔4秒。APIエラーは5秒後に1回だけリトライ。
- **排他制御**：ウェブアプリとトリガーはスクリプトロックで直列化。トリガー処理中にウェブから送ると「保存のみ」で返し、次のトリガーで記録される。
- **日付が読めない場合**：ファイルの作成日を使い、ログに残す。

## セキュリティ

- APIキーはスクリプトプロパティのみに保存。コードとリポジトリには入れない。
- `.clasp.json` / `.clasprc.json` は `.gitignore` で除外。
- ウェブアプリは `access: MYSELF` で本人のGoogleアカウントのみ。
- Gemini無料枠では送信データがGoogleのサービス改善に使われる可能性がある（レシート程度なら許容と判断）。
